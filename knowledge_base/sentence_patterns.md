# 高分句型

## 1. It is + adj + for sb to do sth

It is important for students to develop independent thinking.

## 2. There is no doubt that ...

There is no doubt that technology has changed our daily life.

## 3. Not only ... but also ...

AI can not only improve learning efficiency but also provide personalized feedback.

## 4. The more ..., the more ...

The more we practice writing, the more confident we will become.

## 5. Compared with ...

Compared with traditional learning methods, AI tools are more flexible.

## 6. What matters most is that ...

What matters most is that students should use AI wisely.
