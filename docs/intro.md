# AI 英语作文批改器项目说明

这本 Jupyter Book 用来帮助你理解这个项目的代码结构和运行流程。

项目的目标是做一个网页工具：

1. 用户输入作文题目，或者上传题目图片自动识别文字。
2. 用户输入英语作文，或者上传作文图片自动识别文字。
3. 程序把题目、作文和知识库内容组合成提示词。
4. 大模型返回作文批改结果。

核心文件如下：

| 文件 | 作用 |
| --- | --- |
| `app.py` | Streamlit 网页界面，负责输入、上传图片、展示结果 |
| `ocr.py` | 图片文字识别，把题目或作文图片转成文本 |
| `main.py` | 调用大模型进行作文批改 |
| `prompt.py` | 生成给大模型的批改提示词 |
| `rag.py` | 读取 `knowledge_base` 里的评分标准和写作资料 |
| `.env` | 保存 API Key、模型名、接口地址等配置 |
